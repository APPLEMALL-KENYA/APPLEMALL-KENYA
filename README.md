# Eugine Lihambo — Software Developer Portfolio

A responsive, dark-theme portfolio presenting software engineering work, product case studies and technical capabilities.

## Stack
- Semantic HTML
- Responsive CSS with a custom design system
- Vanilla JavaScript
- GitHub Pages-ready static site

## Run locally
Open `index.html` in a browser or serve the directory with a static HTTP server.

## Deploy
Enable GitHub Pages in repository settings and select the `main` branch with `/(root)` as the publishing source. A GitHub Actions workflow can be added after Pages is enabled.
