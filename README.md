# Eugine Lihambo — Software Developer Portfolio

A responsive, dark-theme, multi-page portfolio presenting software engineering work, product case studies and technical capabilities.

## Case studies
- [Applemall](applemall.html) — multi-vendor e-commerce and commerce operations. Public storefront: https://applemall.co.ke/
- [Drivora](drivora.html) — Django REST backend and Flutter driver jobs/services marketplace. Source: https://github.com/APPLEMALL-KENYA/Drivora
- [Gavy OS](gavy-os.html) — school-management product initiative.
- [Gavy Social](gavy-social.html) — social-publishing product initiative.

## Stack
- Semantic HTML
- Responsive CSS with a custom design system
- Vanilla JavaScript
- GitHub Pages-ready static site

## Run locally
Open `index.html` in a browser or serve the directory with a static HTTP server.

## Deploy
Enable GitHub Pages in repository settings and select the `main` branch with `/(root)` as the publishing source, or configure GitHub Actions as the deployment source.

## Evidence and access
The Applemall public storefront is linked. Privileged administration interfaces are not exposed; the case study documents administrative workflows without offering admin access. Screenshots containing customer, vendor or account information must be redacted before publication. Do not commit secrets, credentials or personal customer data.

Gavy OS and Gavy Social are explicitly labelled as product initiatives, not represented as publicly released services.
